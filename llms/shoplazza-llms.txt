# Shoplazza

> Shoplazza is a global e-commerce SaaS platform for building and running online stores. Partners extend it with public apps, payment apps, storefront themes, and checkout/theme extensions via the versioned REST Admin API (OAuth 2.0, webhooks, app billing). Backed by SoftBank Vision Fund. This llms.txt was generated by API Evangelist from Shoplazza's public developer docs and OpenAPI 3.1 spec.

## APIs

- [Shoplazza Admin API (reference)](https://www.shoplazza.dev/api/openapi): Read/write products, orders, customers, discounts, gift cards, metafields, webhooks, themes, pages, files, shop, app proxy, and app billing.
- [OpenAPI 3.1 spec (SPZ Admin API)](https://raw.githubusercontent.com/Shoplazza/shoplazza-openapi/main/spz-open-api.json): Official machine-readable specification.

## Authentication & Authorization

- [Authentication overview](https://www.shoplazza.dev/docs/app/building-blocks/authentication/): OAuth 2.0 authorization code grant; access token sent in the access-token header.
- [Access scopes](https://www.shoplazza.dev/docs/app/building-blocks/authentication/access-scopes/): read_/write_ scopes for shop, product, order, customer, collection, price_rules, gift_cards, finance, and more.
- [HMAC signature verification](https://www.shoplazza.dev/docs/app/building-blocks/authentication/): Verify OAuth callbacks and webhook authenticity.

## Building blocks

- [REST API conventions](https://www.shoplazza.dev/docs/app/building-blocks/rest-api/): Versioning, rate limits, cursor pagination, common parameters, HTTP status codes.
- [Webhooks](https://www.shoplazza.dev/docs/app/building-blocks/webhooks/overview): Subscribe to store events (products/create, orders/create, app/uninstalled, ...).
- [Billing](https://www.shoplazza.dev/docs/app/building-blocks/billing/overview): One-time, recurring, and usage-based app charges.

## Developer tools

- [Shoplazza CLI](https://www.shoplazza.dev/docs/app/developer-tools/shoplazza-cli/): Build, preview, and deploy apps/themes/extensions; three-layer command system; AI-agent-friendly output.
- [App Bridge](https://www.shoplazza.dev/docs/app/developer-tools/app-bridge/): Embed apps in the Shoplazza admin with session tokens.
- [API libraries (SDK)](https://www.shoplazza.dev/docs/app/developer-tools/api-libraries): Official OAuth SDKs for Go and PHP.
